# DiskPie — 磁碟空間圓餅圖

Windows 11 用的本機硬碟空間分析工具。掃描指定磁碟後，用圓餅圖呈現各資料夾占用的空間；
點選任何一塊（或表格中的任一列），就展開該資料夾，看到它底下所有子目錄與各自的容量。

不需要安裝任何套件，只要有 Python 3.8 以上（Windows 內建的 3.11 就可以）。

## 啟動

雙擊 `DiskPie.bat`，或在命令列執行：

```bash
python diskpie.py
```

也可以直接指定要掃描的目標，開起來就會自動開始掃：

```bash
python diskpie.py C:\
```

其他選項：`--port 8777` 指定連接埠、`--no-browser` 不自動開瀏覽器。
程式會在瀏覽器開啟 `http://127.0.0.1:<port>/`；**關掉命令列視窗就結束程式**。

## 怎麼用

1. 從「掃描目標」下拉選單挑一顆本機磁碟（會顯示每顆的已用／總容量），或在右邊欄位直接打一個資料夾路徑。
2. 按「開始掃描」。掃描過程會即時顯示已處理的資料夾數、檔案數與累計大小；隨時可以按「停止」。
3. 掃完之後：
   - **點圓餅的任一塊** 或 **點表格的任一列** → 展開該資料夾的下一層。
   - **點圓餅中間的空白** 或按 `Backspace` / `Alt+←` → 回上一層。
   - 上方麵包屑可以跳回路徑中的任何一層。
   - 「在檔案總管開啟」會用檔案總管打開目前這一層，方便直接刪東西。
   - 刪完之後按 **「重新掃描此層」**，只重掃這個子資料夾（很快），上層的容量會一起更新，不必整顆重掃。

掃描結果放在記憶體裡，所以掃完之後在各層之間切換都是瞬間的。

## 圖表怎麼讀

- 圓餅畫**最大的 15 個項目**，第 16 名以後合併成一塊「其他 N 個項目」。
  配色分兩段：**前 8 名**用通過色盲辨識度驗證的類別色（藍、橘、青、黃、洋紅、綠、紫、紅），
  **第 9～15 名**改用灰階，深淺代表名次——因為可靠的類別色只有 8 個，再生新色在色盲模擬下會和既有的撞在一起。
  灰階那幾塊的身分由圖上標示、滑鼠停留的提示框與右側表格辨認。
  右側表格則列出**全部**項目（超過 300 筆時可按鈕展開），並附上顏色標記、大小、占比與長度條。
  想改數量的話，調整 `web/app.js` 最上面的 `PIE_ITEMS` 即可。
- 占比 7% 以上的區塊會在圖上直接標出百分比，12% 以上連名稱一起標。
- 「（本層檔案 N 個）」代表這一層直接放的檔案（不含子資料夾），它也會參與排序與配色，但不能再往下點。
- 展開頁下方的「本層最大的檔案」列出這一層最大的 15 個檔案。
- 配色在淺色與深色模式下各自取階，並通過色盲辨識度驗證；右上角 `◐` 可切換 自動 / 淺色 / 深色。

## 幾件要知道的事

- **大小是檔案的邏輯大小**（`st_size`）的加總，和檔案總管的「大小」一致；不是「磁碟上的大小」，
  所以壓縮磁碟區、稀疏檔或大量小檔案時，總和會和「內容大小」略有出入。
- **捷徑、junction、symlink 一律不追進去**，避免同一份資料被算兩次或掃到無限迴圈。
  OneDrive 這類雲端佔位檔同理會被略過。
- **沒有權限的資料夾**（例如 `System Volume Information`、`Recovery`）會標上「無權限」，其容量算 0。
  想把這些也算進去，就用系統管理員身分執行。
- **合計不會等於檔案總管顯示的「已用空間」**，通常會少個一到三成。差額來自無權限的資料夾、
  被略過的連結點、NTFS 本身的中繼資料與磁碟區陰影複製（還原點）。這是這類工具的常態——
  它要回答的是「**哪個資料夾最肥**」，不是「磁碟到底用掉幾 GB」。
- 掃整顆系統碟大約 1–3 分鐘（第一層子目錄會分 8 個執行緒平行掃）。第二次掃同一顆會因為
  Windows 的檔案系統快取而明顯變快。
- 工具**只讀不寫**：不會刪除或搬移任何檔案。要刪東西請用「在檔案總管開啟」自己動手，再回來按「重新掃描此層」。

## 安全性

HTTP 伺服器只綁 `127.0.0.1`，而且每次啟動會產生一組隨機權杖，所有 `/api/*` 請求都必須帶上
`X-DiskPie-Token`，避免其他網頁在你的瀏覽器裡偷打這個本機服務。

└─ web/
